# Sheng Detector 🇰🇪

A Python tool to analyse code-switching between Sheng, Swahili and English in Kenyan classrooms.

## Why I built this
I am Winnie Kortok, a linguistics student from Ruiru, Kenya. I study how my students mix Sheng, Swahili and English in one sentence. I built this tool to count and measure that mixing.

## What it does
Type a sentence like: "Mambo, leo my friend anadai tutaenda town"

It will tell you:
- How many words are Sheng
- How many are Swahili
- How many are English
- The percentage for each

## How to run it
python detector.py

## Example
Mambo -> SHENG
leo -> SWAHILI
my -> ENGLISH
